# Episodic and semantic retrieval

Use the host's exposed `memory_search` schema (`query`, authorized `group_id`,
and `limit`) and inspect get/list schemas before using their identifiers.
Retrieve relevant episodic outcomes and canonical semantic evidence through
the same governed interface. Reconcile dated decisions with current source.

PostgreSQL/RuVector storage details do not authorize raw queries. Distinguish
graph health, semantic retrieval freshness, and episodic stream freshness.
Missing search results are not proof of a failed graph. Report evidence and
unverified capabilities separately; never infer active health from legacy keys.
