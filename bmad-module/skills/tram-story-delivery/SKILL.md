# Team RAM Story Delivery

1. Read the authoritative story and sprint status.
2. Run Scout and hydrate only task-relevant Allura context.
3. Route one writer through `bmad-dev-story`.
4. Run independent Pike/Fowler review on the actual diff.
5. Run explicit validation and current-SHA CI where required.
6. Record a concise governed receipt and update status only with evidence.

Do not run multiple writers in one worktree or mark work done from a plan or commit alone.
